本次安全修复后，需要配置环境变量才能正常运行项目。

## 📋 配置步骤

### 1. 本地 Mac 环境配置

#### 在项目根目录创建 `.env` 文件

```bash
cd /Users/wangliang/Desktop/Mylife/backend
cp .env.example .env
```

#### 编辑 `.env` 文件，设置以下变量：

```bash
# Django SECRET_KEY (必须设置)
# 使用下方命令生成一个新密钥，然后填入此处
DJANGO_SECRET_KEY=$xj_7$8m#w7)1-nc69mx4+q(-@b&ib#))!*cm29+h=(w1v)fh^

# Django DEBUG 模式
# 本地开发设置为 True，生产环境必须为 False

# Django ALLOWED_HOSTS (可选)
# 如果不设置，将使用 settings.py 中的默认值
# DJANGO_ALLOWED_HOSTS=localhost,127.0.0.1,192.168.31.142
```

**或者直接运行：**

```bash

```

#### SSH 登录云服务器后执行：


**注意：云服务器必须生成一个新的SECRET_KEY，不要使用本地生成的密钥！**

## ⚠️ 注意事项

1. **不要将 `.env` 文件提交到Git**
   - `.env` 文件已在 `.gitignore` 中
   - 确保敏感信息不会被泄露

2. **不同环境使用不同的SECRET_KEY**
   - 本地开发环境使用一个密钥
   - 云服务器生产环境使用另一个密钥
   - 不要在不同环境间共享密钥

3. **生产环境必须设置 DEBUG=False**
   - 如果设置为 True，会暴露敏感信息
   - 影响系统安全

4. **SECRET_KEY一旦设置不要随意更改**
   - 更改会导致所有session失效
   - 用户需要重新登录

## 🔄 迁移说明

### 从旧配置迁移

如果你之前没有使用 `.env` 文件，系统会自动：
- 如果没有设置 `DJANGO_SECRET_KEY`，会自动生成一个新的（仅用于开发）
- `DEBUG` 默认为 `False`（生产环境安全）
- `ALLOWED_HOSTS` 使用默认列表

**但是，建议立即配置 `.env` 文件以确保：**
- SECRET_KEY 稳定（不每次启动都变化）
- DEBUG 模式可以控制
- 配置更清晰

## 📝 环境变量说明

| 变量名 | 必需 | 说明 | 示例值 |
|--------|------|------|--------|
| `DJANGO_SECRET_KEY` | ✅ 是 | Django密钥，用于加密 | 自动生成 |
| `DJANGO_DEBUG` | ✅ 是 | 调试模式 | `True`(开发) / `False`(生产) |
| `DJANGO_ALLOWED_HOSTS` | ❌ 否 | 允许的主机列表 | `localhost,xiaomanxia.com` |
