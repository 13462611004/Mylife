## 可能的问题

### 1. 阿里云安全组未开放端口 ⚠️

**症状**: 外网无法访问 80 端口（连接超时）

**解决方案**:
1. 登录阿里云控制台
2. 进入 **ECS实例** → 选择您的服务器
3. 点击 **安全组** → **配置规则**
4. 添加入站规则：
   - **端口**: 80/80 (HTTP)
   - **协议**: TCP
   - **授权对象**: 0.0.0.0/0
   - **描述**: FRP HTTP 访问

   - **端口**: 443/443 (HTTPS)
   - **协议**: TCP
   - **授权对象**: 0.0.0.0/0
   - **描述**: FRP HTTPS 访问

5. 点击 **保存**

### 2. DNS 解析未配置 ⚠️

**症状**: 域名无法解析到服务器 IP

**检查方法**:
```bash
# 在本地执行
nslookup xiaomanxia.com
# 或
dig xiaomanxia.com
```

**解决方案**:
1. 登录域名注册商管理后台
2. 添加 DNS 解析记录：
   - **类型**: A
   - **主机记录**: @ (或留空)
   - **记录值**: 8.153.81.3
   - **TTL**: 600

   - **类型**: A
   - **主机记录**: www
   - **记录值**: 8.153.81.3
   - **TTL**: 600

   - **类型**: A
   - **主机记录**: api
   - **记录值**: 8.153.81.3
   - **TTL**: 600

3. 等待 DNS 生效（通常 5-30 分钟）

### 3. 临时测试方案（无需域名）

在 DNS 配置完成前，可以使用 **TCP 代理** 直接通过 IP 访问：

**访问地址**:
- 前端: http://8.153.81.3:3000
- 后端: http://8.153.81.3:8000

如果 TCP 代理也无法访问，说明安全组没有开放 3000 和 8000 端口。

## 常见错误及解决

### 错误: "Connection timed out"
- **原因**: 安全组未开放端口
- **解决**: 在阿里云控制台配置安全组规则

### 错误: "no route found" (FRP 日志)
- **原因**: Host 头不匹配
- **解决**: 使用正确的域名访问，或配置 DNS

### 错误: "404 Not Found"
- **原因**: Nginx 配置问题或 FRP 路由问题
- **解决**: 检查 Nginx 配置和 FRP 日志
